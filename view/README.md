# Results Browser UI

React/Vite/TypeScript/Mantine results browser for the
Style-Conditioned Piano Accompaniment Generation thesis.

## What it shows

- A melody selector (populated from `view/public/demo/index.json`)
- A comparison grid: rows = system layers, columns = Baroque / Romantic
- Each cell: play button, provenance badge, classifier metrics
- An A/B toggle to hear Baroque vs. Romantic from the same position
- A "Method & Honesty" panel with evaluation numbers

## Running locally

```bash
cd view
npm install
npm run dev
# Open http://localhost:5173
```

## Building for production

```bash
npm run build
# Output in view/dist/
```

## Data source

The UI reads `view/public/demo/index.json`, which is generated by:

```bash
python scripts/build_demo_index.py --config config.yaml
```

This script reads `results/generation_log.csv` and `results/evaluation_results.csv`,
copies WAV files to `view/public/demo/`, and writes the JSON index.

## Empty state

If `index.json` has `"_empty": true` (no pipeline results yet), the UI shows
a clear empty state with the commands needed to run the pipeline.
It never shows fake audio or mock data.

## No live generation

Generation runs offline on a Colab GPU. There is no "Generate" button.
The UI is a static results browser only.
